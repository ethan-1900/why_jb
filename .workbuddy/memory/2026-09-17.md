## 发布链路备忘

编辑 `Why JB.md` → `python3 scripts/subset_font.py --check` → `python3 scripts/build.py`
→ `git push origin main` → Pages 约 1 分钟构建（`gh api repos/ethan-1900/why_jb/pages/builds/latest` 看状态）。
Pages 的 CDN 忽略查询参数，`?v=` 不能刷新缓存，旧内容最长约 10 分钟后才被替换；
换路径（如 `/why_jb/index.html`）可立刻取到新版本。
