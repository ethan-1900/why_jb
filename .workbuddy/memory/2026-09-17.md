## 字体子集缺字修复 + 背景音乐播放器（commit 26dce9e，已推送）

- 用户怀疑「打打单机」的「打打」与其他中文格式不一致，核查属实：自托管子集
  `assets/source-han-serif-sc-subset.woff2` 未收录 U+6253「打」，全文仅此一字缺失。
  在装有思源宋体的本机看不出差别，其他设备会回退到 Songti SC / SimSun，字形字重不一致。
- 新增 `scripts/subset_font.py`（默认重新生成，`--check` 只报告），从
  `~/Library/Fonts/SourceHanSerifSC-Regular.otf` 重建子集（672 → 542 码位，187 KB）。
- `scripts/build.py` 增加构建期缺字检查（fontTools 缺失时静默跳过）并打印提醒；
  同时改为把 `_site/index.html` 复制到仓库根目录——根目录的 index.html 才是
  GitHub Pages 实际发布的文件（此前靠手工复制）。
- 背景音乐：`template.html` 加 `#bgm` 音频 + 右下角 `.bgm-toggle` 按钮，
  自动播放尝试（音量 0.25、1.6 秒淡入）失败则首次点击/按键起播；无音频文件时按钮自动隐藏。
  样式在 `assets/style.css` 末尾（含 `.bgm-*` 与 bgm-bar / bgm-nudge 动画）。
  音频待放置于 `assets/audio/bgm.mp3`（用户想用 JB 的 home to mama 或 love yourself）。
- 小坑：沙箱下 `Path.mkdir(exist_ok=True)` 对已存在目录会抛 PermissionError，
  改 `parents=True, exist_ok=True` 即可。

## 发布链路备忘

编辑 `Why JB.md` → `python3 scripts/subset_font.py --check` → `python3 scripts/build.py`
→ `git push origin main` → Pages 约 1 分钟构建（`gh api repos/ethan-1900/why_jb/pages/builds/latest` 看状态）。
Pages 的 CDN 忽略查询参数，`?v=` 不能刷新缓存，旧内容最长约 10 分钟后才被替换；
换路径（如 `/why_jb/index.html`）可立刻取到新版本。
